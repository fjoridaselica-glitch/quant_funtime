SECTION 02

Mathematical Architecture

01. GEOMETRIC BROWNIAN MOTION

Log-Normal Asset Dynamics

Stock price movements are modeled using continuous-time stochastic differential equations (SDEs), ensuring asset values remain positive while capturing drift and random shocks.

$$dS_t = \mu S_t dt + \sigma S_t dW_t$$
02. ITÔ'S LEMMA DRIFT

Volatility Drag Adjustment

Compounding discrete daily returns creates variance drag. We subtract $\frac{1}{2}\sigma^2$ from mean daily returns to ensure unbiased log return projections over time horizons.

$$\text{Drift} = \mu - \frac{1}{2}\sigma^2$$
03. CHOLESKY DECOMPOSITION

Multivariate Cross-Correlation

To maintain historical co-movement between stocks (e.g., AAPL and MSFT), independent standard normal random vectors $Z$ are transformed using lower-triangular matrix $L$.

$$\Sigma = L \cdot L^T \implies X = L \cdot Z$$

import numpy as np
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt


# 2. Asset Universe and Allocation Weights (70% Growth / 30% Value Core)
tickers = ['AAPL', 'MSFT', 'JPM', 'XOM']
weights = np.array([0.40, 0.30, 0.15, 0.15])

# 3. Retrieve Historical Price Data
df = yf.download(tickers, start='2023-01-01', end='2024-01-01', auto_adjust=True)['Close'].dropna()

# 4. Returns & Covariance Matrix Computation
returns = df.pct_change().dropna()
mean_daily_returns = returns.mean()
cov_matrix = returns.cov()

# 5. Lower Triangular Cholesky Matrix Decomposition
L = np.linalg.cholesky(cov_matrix)

# 6. Hyperparameters
num_simulations = 150
time_horizon = 90
initial_portfolio = 30000

portfolio_sims = np.zeros((time_horizon, num_simulations))

# 7. Itô's Lemma Drift Adjustment (mu - 0.5 * sigma^2)
drift = mean_daily_returns.values - (0.5 * np.diag(cov_matrix))

# 8. Correlated Monte Carlo Path Generation
for i in range(num_simulations):
    Z = np.random.normal(size=(time_horizon, len(weights)))
    correlated_returns = drift + np.dot(Z, L.T)
    portfolio_returns = np.dot(correlated_returns, weights)
    portfolio_sims[:, i] = np.cumprod(portfolio_returns + 1) * initial_portfolio

# 9. Output Visualization
plt.figure(figsize=(10, 6))
plt.plot(portfolio_sims, alpha=0.3, color='#1d4ed8')
plt.title('Monte Carlo Correlated Portfolio Simulation')
plt.xlabel('Days')
plt.ylabel('Portfolio Value ($)')
plt.grid(True, linestyle='--', alpha=0.4)
plt.show()
