Monte Carlo Portfolio Simulation

Project Inspiration

This project was heavily inspired by the educational content of QuantPy on YouTube. It implements a multi-asset portfolio forecasting model using Python, historical stock price data, and Cholesky decomposition to capture asset covariance.

Key Features

• Pulls historical market data using pandas_datareader.
• Calculates daily mean returns and the portfolio covariance matrix.
• Applies Cholesky decomposition to correlate random normal sampling.
• Projects 100-day price trajectories across 100+ Monte Carlo iterations.
