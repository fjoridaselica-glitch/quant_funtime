Project Overview

Financial asset prices do not move independently; they are bound together by market trends, macroeconomic factors, and industry co-dependencies. Standard Monte Carlo simulations that ignore asset correlations produce unrealistic portfolio trajectories.

This project models future multi-asset stock portfolio scenarios over a specified time horizon (e.g., 100 days) using historical market returns fetched via financial APIs. By calculating daily mean return vectors and generating a covariance matrix, we use Cholesky decomposition to transform uncorrelated standard normal random shocks into correlated asset movements.

Key Mathematics: Covariance & Cholesky Decomposition

01. The Covariance Matrix ($\Sigma$)

Covariance measures how much two assets move in tandem. Given daily log returns for $N$ stocks, the sample covariance between asset $X$ and asset $Y$ is defined as:

$$\text{Cov}(X, Y) = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{n - 1}$$

The full matrix $\Sigma$ captures variance along its diagonal and pairwise covariances in off-diagonal cells.

02. Cholesky Factorization ($L$)

To inject correlation into independent random numbers $Z \sim \mathcal{N}(0, I)$, we decompose the positive semi-definite covariance matrix into a lower triangular matrix $L$:

$$\Sigma = L \cdot L^T$$

Multiplying $L \cdot Z$ transforms independent normal variables into correlated random variables whose covariance equals $\Sigma$.

Core Python Logic

Below is a snippet illustrating how historical returns are fetched, converted to covariance matrices, and sampled via Cholesky decomposition using Python and NumPy: 

import numpy as np
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt

# Tickers
tickers = ['TLS.AX', 'NAB.AX', 'WBC.AX', 'STO.AX']
df = yf.download(tickers, start='2023-01-01', end='2024-01-01', auto_adjust=True)['Close']

# Drops rows with missing values
df = df.dropna()

# Calculates Returns and Covariance
returns = df.pct_change().dropna()
mean_daily_returns = returns.mean()
cov_matrix = returns.cov()

# Computes Cholesky Matrix L
L = np.linalg.cholesky(cov_matrix)

# Monte Carlo Parameters
num_simulations = 100
time_horizon = 100
portfolio_sims = np.full((time_horizon, num_simulations), 0.0)

initial_portfolio = 10000
weights = np.array([0.25, 0.25, 0.25, 0.25])

# Runs Simulation Loop
for i in range(num_simulations):
    Z = np.random.normal(size=(time_horizon, len(weights)))
    correlated_returns = mean_daily_returns.values + np.dot(Z, L.T)
    portfolio_returns = np.dot(correlated_returns, weights)
    portfolio_sims[:, i] = np.cumprod(portfolio_returns + 1) * initial_portfolio

# Renders Plot
plt.figure(figsize=(10, 6))
plt.plot(portfolio_sims)
plt.title('Monte Carlo Portfolio Simulation (ASX Assets)')
plt.xlabel('Days')
plt.ylabel('Portfolio Value ($)')
plt.grid(True)
plt.show()
