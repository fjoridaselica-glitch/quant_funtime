01. Project Overview

Financial asset prices do not move independently; they are bound together by market trends, macroeconomic factors, and industry co-dependencies. Standard Monte Carlo simulations that ignore asset correlations produce unrealistic portfolio trajectories.

This project models future multi-asset stock portfolio scenarios over a specified time horizon (e.g., 100 days) using historical market returns fetched via financial APIs. By calculating daily mean return vectors and generating a covariance matrix, we use Cholesky decomposition to transform uncorrelated standard normal random shocks into correlated asset movements.

02. Mathematical Framework

A. The Covariance Matrix ($\Sigma$)

Covariance measures how much two assets move in tandem. Given daily log returns for $N$ stocks, sample covariance between asset $X$ and asset $Y$ is defined as:

$$\text{Cov}(X, Y) = \frac{\sum (X_i - \bar{X})(Y_i - \bar{Y})}{n - 1}$$

The full matrix $\Sigma$ captures asset variance along its diagonal and pairwise covariances in off-diagonal cells.

B. Cholesky Factorization ($L$)

To inject correlation into independent random numbers $Z \sim \mathcal{N}(0, I)$, we decompose the positive semi-definite covariance matrix into a lower triangular matrix $L$:

$$\Sigma = L \cdot L^T$$

Multiplying $L \cdot Z$ transforms independent normal variables into correlated random variables matching covariance matrix $\Sigma$.

03. Python Implementation

portfolio_simulation.py 
import numpy as np
import pandas as pd
import yfinance as yf
import matplotlib.pyplot as plt

tickers = ['AAPL', 'MSFT', 'JPM', 'XOM']
weights = np.array([0.40, 0.30, 0.15, 0.15])  # 70% Growth / 30% Value

df = yf.download(tickers, start='2023-01-01', end='2024-01-01', auto_adjust=True)['Close'].dropna()

returns = df.pct_change().dropna()
mean_daily_returns = returns.mean()
cov_matrix = returns.cov()

# Cholesky Decomposition
L = np.linalg.cholesky(cov_matrix)

num_simulations = 150
time_horizon = 90
initial_portfolio = 30000

portfolio_sims = np.zeros((time_horizon, num_simulations))

# Drift adjustment (Itô's Lemma correction)
drift = mean_daily_returns.values - (0.5 * np.diag(cov_matrix))

for i in range(num_simulations):
    Z = np.random.normal(size=(time_horizon, len(weights)))
    correlated_returns = drift + np.dot(Z, L.T)
    portfolio_returns = np.dot(correlated_returns, weights)
    portfolio_sims[:, i] = np.cumprod(portfolio_returns + 1) * initial_portfolio

# Visual Output
plt.figure(figsize=(10, 6))
plt.plot(portfolio_sims, alpha=0.35)
plt.title(f'Monte Carlo Portfolio Simulation ({", ".join(tickers)})')
plt.xlabel('Days')
plt.ylabel('Portfolio Value ($)')
plt.grid(True, linestyle='--', alpha=0.5)
plt.show()
